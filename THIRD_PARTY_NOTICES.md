### Architecture / reference only (Class A)

- Synthetic provider via `ctx.llm.registerAdapter` declaring `inputModalities: ['text','image']` to unlock image admission while delegating to a text-only upstream (the "vision wrapper" concept).
- Request-time conversion that leaves the durable session log (ImageBlock attachment ref) untouched and rewrites only the wire messages.
- Evidence generated by an image-capable model route and handed to the text-only reasoning model as text.
